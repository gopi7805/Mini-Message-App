# Mini Message App

## About the Project

Mini Message App is a small full stack application developed to send and display messages through a user-friendly interface. It connects a frontend application with a Java Spring Boot backend.

## Project Structure

- **Backend:** Handles application logic and message-related API operations.
- **Frontend:** Provides the user interface for interacting with the application.
- **Downloads:** Contains the project-related downloaded files.

## Technologies Used

- Java
- Spring Boot
- REST APIs
- HTML
- CSS
- JavaScript
- Docker

## Features

- Send messages through the application.
- Display messages in the user interface.
- Connect frontend with backend APIs.
- Handle message-related operations.

## Backend

The backend is developed using Java and Spring Boot to handle application logic and API requests.

## Frontend

The frontend provides an interface for users to interact with the Mini Message App.
